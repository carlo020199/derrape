# Cómo empezar (10 minutos)

1. **Instala en tu PC** (si no lo tienes):
   - Node.js LTS → https://nodejs.org
   - Git → https://git-scm.com
   - Claude Code → sigue la guía oficial en https://docs.claude.com (sección Claude Code)
2. **Descomprime** esta carpeta `derrape` donde guardes tus proyectos (p. ej. `Documentos/proyectos/derrape`).
3. **Abre una terminal** en esa carpeta y ejecuta:
   ```
   claude
   ```
4. **Pega el prompt de la Fase 0** que está en `docs/PROMPTS.md`.
5. Cuando termine, prueba `npm run dev` y ábrelo en el navegador. Luego sigue con la Fase 1.

Archivos:
- `CLAUDE.md` → reglas del proyecto. Claude Code lo lee solo en cada sesión. No lo borres.
- `docs/PLAN.md` → el plan completo: diseño del juego, fases y checklist de móvil.
- `docs/CONTENIDO.md` → los 10 circuitos, 5 personajes y 10 coches (nombres y estadísticas editables).
- `docs/PROMPTS.md` → un prompt listo para cada fase.

Para retomar otro día: abre `claude` en la carpeta y escribe
"Lee CLAUDE.md y docs/PLAN.md, mira git log y dime en qué punto estamos y qué toca."
